Place your Woblo.woff file in this folder as:

  frontend/src/fonts/Woblo.woff

index.css already declares the @font-face pointing at that exact path and
exposes it as the ".woblo-font" class, used on the ASTRA 2K26 wordmark in
Header.jsx. Until the real file is added here, browsers will silently fall
back to the sans-serif font defined in --font-display, so the site still
works correctly — it just won't show the Woblo look until the font file
is in place.
